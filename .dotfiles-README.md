# rayxaus dotfiles

Backup of this Arch/Hyprland system's hand-edited config. Tracked with a bare
git repo pointed at `$HOME` (no symlinks) — see the `dotfiles` alias in
`.bashrc`:

```
alias dotfiles='/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'
```

## What's tracked

- `.bashrc`, `.bash_profile`
- `.config/hypr` — Hyprland
- `.config/hyprpanel` — panel
- `.config/wayle` — bar/theme
- `.config/zed/settings.json` — editor settings
- `.config/dolphinrc`, `.config/mimeapps.list`
- `.config/Happ/config.json` — proxy client routing config (no credentials)
- `.config/dotfiles-meta/pacman-explicit.txt` — `pacman -Qqe` snapshot
- `.config/dotfiles-meta/aur-packages.txt` — `pacman -Qqem` snapshot (AUR/foreign)

## Deliberately NOT tracked

- `.config/Happ/subs.db` and `.config/Happ.conf` — contain VPN subscription
  data (`subs.db` looks like an encrypted subscription token)
- App caches/state: `.config/Claude`, `.config/mozilla`, `.config/dconf`,
  `.config/pulse`, `.config/session`, `.config/go`
- Anything else not explicitly added

## Restoring on a fresh machine

```bash
git clone --bare <this-repo-url> "$HOME/.dotfiles"
alias dotfiles='/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'
dotfiles checkout
dotfiles config status.showUntrackedFiles no

# reinstall packages
sudo pacman -S --needed - < ~/.config/dotfiles-meta/pacman-explicit.txt
# then install AUR packages from aur-packages.txt with your AUR helper
```

If `checkout` complains about existing files, back them up first:

```bash
mkdir -p ~/.config-backup
dotfiles checkout 2>&1 | grep -E "^\s+" | awk {'print $1'} | \
  xargs -I{} mv {} ~/.config-backup/{}
dotfiles checkout
```
